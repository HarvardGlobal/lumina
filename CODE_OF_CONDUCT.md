# Code of Conduct

We are committed to a respectful, inclusive, and professional community.
Participants must communicate constructively, respect differing viewpoints,
protect confidential and health-related information, and avoid harassment,
discrimination, intimidation, or personal attacks.

Maintainers may remove content, limit participation, or take other appropriate
action for behaviour that violates these standards. Report concerns privately
through the security/contact channel described in [SECURITY.md](SECURITY.md).

This code applies in repository discussions, issues, pull requests, and other
project spaces.
